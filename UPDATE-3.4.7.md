- На екрані отримувача оновлено заголовок, відступи, кнопку та кольори; прибрано світіння тексту.
- Нова послідовність відкриття: зняття печатки, розкриття клапана, вихід паперу та плавна поява листа. Повторні натискання захищено. Для prefers-reduced-motion перехід відбувається одразу.
- Версія кешу Service Worker оновлена.

## Як оновити наявний Worker

Розпакуйте проєкт, збережіть свої налаштування `wrangler.jsonc`, якщо змінювали їх, і виконайте в каталозі проєкту:

```sh
npm install
npm run check
npm run deploy
```

Для цього оновлення не потрібні нові секрети, міграції бази чи повторне налаштування бота. Архів містить повний проєкт, а не лише змінені файли. Публікація на сервер у межах підготовки архіву не виконувалася.

## Перевірено

- Перевірка синтаксису Worker та всіх п’яти вбудованих скриптів: PASS.
- У локальному браузері: початково згорнуті блоки, вибір шрифту та підстановка готового тексту; фон внизу редактора, ширина 320 px без горизонтального переповнення.
- Внутрішня прокрутка з CSS-режимом Telegram Mini App на 390 px.
- Послідовність отримувача: вступ → конверт → лист → вибір → фінал; без JavaScript-помилок під час цього сценарію.

Перевірки виконані з локальними тестовими відповідями API. Реальний iPhone/Safari, Telegram WebView, платежі та production API не тестувалися.
