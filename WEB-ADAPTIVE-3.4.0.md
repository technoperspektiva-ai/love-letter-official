# Love Letter 3.4.0 — adaptive web mode

- Full responsive browser mode for Safari and Chrome when enabled by the owner.
- Telegram authentication in the browser is confirmed through `@loveletter_official_bot`; the legacy Telegram Login Widget is no longer required.
- The owner can globally enable/disable browser author access.
- Recipient letter links stay public in normal browsers.
- Page zoom is locked to keep the app-like layout stable on iPhone and Android browsers.
