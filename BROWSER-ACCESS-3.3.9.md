# Love Letter 3.3.9 — Telegram-only creator mode

- Створення листів вимагає Telegram-авторизацію.
- Авторська частина у звичайному браузері за замовчуванням заблокована.
- `/l/<id>` для отримувачів продовжує працювати у Safari/Chrome.
- У браузері замість редактора показується кнопка переходу в `@loveletter_official_bot`.
- Кнопки встановлення PWA прибрані з продуктового UI.
- Власник Telegram ID `375938798` бачить у налаштуваннях Mini App адмін-перемикач **Доступ через браузер**.
- Налаштування зберігається в D1 `app_settings.browser_access_enabled`.
- За замовчуванням значення `0` (вимкнено).
